A lightweight AI-powered receipt verification module that allows users to upload payment receipts and automatically validates them using OCR, metadata analysis, and smart matching.

Features
📤 Upload: Screenshot, photo, or PDF
🔍 Auto verification:
OCR / PDF text extraction
Metadata fraud detection
AI authenticity check
✅ Match:
  . Amount
  . Reference code
⚡ Instant listing activation
🧾 Manual review fallback (within 24h)
🔔 User notifications
Tech Stack
- Frontend: React, Axios, React Router
- Backend: Node.js / Express
- OCR + AI Verification
